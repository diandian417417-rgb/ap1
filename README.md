# AP1 · 交互式 2D 分形（Sierpinski 垫片）

基于 **原生 WebGL 2.0 + JavaScript**（无构建步骤）实现的交互式 Sierpinski 垫片。
分别用 **混沌游戏** 与 **递归细分** 两种算法生成同一图形，支持 **点云 / 线框 / 实体** 三种渲染模式、
鼠标与键盘交互、参数实时调节，并支持 **任意 n 边形垫片（选做 E1）**。

## 一、运行方式

使用了 ES Module（`<script type="module">`），**必须通过静态服务器打开**
（浏览器出于安全策略禁止从 `file://` 加载模块）：

```bash
python -m http.server 8000      # 在本项目目录下执行
```

然后浏览器访问 `http://localhost:8000`。

## 三、两种生成算法

**1) 混沌游戏（Chaos Game）**
从任意初始点 `p` 出发，重复执行：

```
p = (p + 随机选中的一个顶点) / 2
```

迭代几千次后，点会迅速“坍缩”到吸引子上，画出 Sierpinski 垫片。
前 30 步属于暂态（尚未收敛），程序丢弃后再开始记录。

**2) 递归细分（Subdivision）**
把三角形三边中点相连，得到 4 个子三角形，**保留三个角上的、去掉中间那个**，再对每个角上的子三角形递归：

```
subdivide(triangle, depth):
    depth == 0 → 记录为一个叶三角形
    否则把 triangle 切成三个角子三角形，各递归 depth-1
```

深度 `depth` 对应 `3^depth` 个叶三角形，用户可调（0–7）。

两种算法生成的图形相同，但一个靠“随机迭代 + 大数定律”，一个靠“确定性递归细分”。

## 四、交互说明

| 操作 | 效果 |
|---|---|
| 左键拖动 | 平移视图 |
| 滚轮 | 以光标为中心缩放 |
| `1` / `2` / `3` | 切换 点云 / 线框 / 实体 渲染模式 |
| `空格` | 暂停 / 继续“逐点生长”动画 |
| 面板「生成算法」 | 混沌游戏 ↔ 递归细分 |
| 面板「顶点数」 | 混沌游戏点数（1000–100000） |
| 面板「递归深度」 | 细分深度（0–7） |
| 面板「点大小 / 配色」 | 实时调节点大小与 5 套配色 |
| 面板「多边形边数 n」 | E1：3→8 边形混沌游戏 |

**逐点生长动画**：点 / 图元数量从 0 随时间增长到设定值（约 3 秒长满），空格可暂停。
切换参数后会自动重播生长过程。

## 五、实现要点（WebGL 数据流）

1. **数据组织**：几何算法输出 `Float32Array`，按 `[x, y, r, g, b]` 交错排列（stride = 5×4 字节）。
2. **上传 GPU**：`gl.bufferData(gl.ARRAY_BUFFER, ...)` 存入 VBO，VAO 记录两个 attribute 指针。
3. **着色器**：顶点着色器做平移 / 缩放并映射到 NDC；片元着色器输出插值颜色，点云时用 `gl_PointCoord` 裁成圆点。
4. **绘制**：`gl.drawArrays(mode, 0, count)`，`count` 即“生长”进度，实现逐点动画。
5. **交互**：鼠标事件直接修改相机的 `center / scale`；键盘事件修改渲染模式后重建缓冲。

## 七、选做扩展 · E1：任意 n 边形垫片

**实现方式**：把经典三角混沌游戏的“三个吸引顶点”推广为正 **n 边形**的 n 个顶点，
迭代规则完全不变：`p = (p + 随机顶点) / 2`。
面板上的「多边形边数 n」滑条可在 **3–8** 之间实时调整（仅在“混沌游戏”算法下可用）。

**原理**：混沌游戏之所以能画出垫片，靠的是“取中点”这一仿射压缩映射——
每一步都把当前点向某个顶点折半靠近，多次迭代后点的分布会收敛到该映射族的不动点集（吸引子）。
把顶点集合从 3 个换成 n 个，规则本身不变，吸引子就自然地变成 **n 边形垫片（n-gon gasket）**。
换句话说，n 并不需要改写算法，只需要改“顶点表的长度”。

**观察到的差异**：

- **n = 3**：经典 Sierpinski 三角垫片——三个子图只在中点处相切（几乎互不重叠），是标准自相似集，
  分形维数为 log3 / log2 ≈ 1.585。
- **n = 5 / n = 6**：出现五边形 / 六边形垫片，中心孔洞更大、结构更像“多边形网络”。
- **n 越大**：各子图之间的**重叠越多**，图案显得越“厚”、孔洞被更多小图形填充，
  视觉上从“点阵三角形”过渡到更繁密的多边形结构。
  （注意：此时简单按 log n / log2 计算维数已不再成立，因为各副本不再互不重叠。）

**操作**：切到“混沌游戏” → 拖动「多边形边数 n」即可复现上述图案；
配合“配色”和“点大小”能更清楚地看到自相似结构。
